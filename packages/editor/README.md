# @mind-hub/editor (Mind Editor)

> Open-source, extensible Notion-like block editor for Vue 3 and Tiptap v2.

## Features

- 🧱 **Block-First Architecture:** Drag handle gutter (`+` / `⠿`) with fluid ProseMirror drop indicators.
- ⚡ **Slash Commands (`/`):** Instant fuzzy-search command palette with full keyboard navigation.
- 🏷️ **Dual Frontmatter Header:** Visual property manager (tags pills, status, projects) & Raw YAML toggle with collapsible focus view.
- 📊 **Native Mermaid Diagrams:** High-performance live SVG rendering adhering to `mind-light-style` with one-click code toggling.
- 💡 **Markdown-Compatible Callouts:** GitHub/Obsidian syntax (`> [!NOTE]`) with soft pastel accents.
- 🔗 **Page Mentions & Wikilinks:** `@` and `[[...]]` inline chips with hover preview.
- 🛡️ **Zero Lock-In:** Markdown is the pure Single Source of Truth (SSOT).
